An entry for the [make.fun](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735) competition **One Word for the Boss** (u-swift-badger-44-one-word-for-the-boss-6b48c735): exactly one word describing the boss, judged head-to-head by the house judge on funniness, truth and freshness.

## The word

> Hovercraft

A hovercraft floats just above the ground and never quite lands — exactly what the boss does over your shoulder while you work: present, humming, watching, never sitting down, never going away.

## How it works

`main.ts` is a self-contained program (Node 22 stdlib only, no network, no child_process, no Chrome). The word is embedded in it — it reads no files at runtime — and it writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), checking the word stays within the gate: 1 to 30 characters, a single word with no spaces, not only whitespace. It reads the file back to confirm the output is byte-identical.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
